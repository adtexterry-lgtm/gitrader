# 样例数据（assets/samples/）

`docs/user/tutorials/` 三篇教程用的 K 线样例。三份都是**合成数据**：用固定种子的随机游走造出来的，
不是任何交易所的行情，也没有任何市场含义；价格量级只是为了让数字看起来像行情。

| 文件 | 根数 | 周期 | 时间范围（UTC） | 体积 | sha256 |
|---|---|---|---|---|---|
| `btcusdt-1h.csv` | 1500 | 1h | 2025-01-01 00:00 → 2025-03-04 11:00 | 81 808 B | `3c17b8925940984b25d2e664013d97d83d7efef2a5f7b6c07403463d6546b53f` |
| `ethusdt-1h.csv` | 1200 | 1h | 2025-01-01 00:00 → 2025-02-19 23:00 | 61 488 B | `76da81177c8a072d7e58245f62cded44fb599926d15f18cc713ef678dbc5f4de` |
| `solusdt-4h.csv` | 900 | 4h | 2025-01-01 00:00 → 2025-05-30 20:00 | 42 758 B | `16492a6b0c05d3ca48680aedd7b5f5d4db23ba9fc2b0048f51ece5ec033f18df` |

格式与 `@gitrader/data-files` 的解析口径一致：表头 `t,o,h,l,c,v`，一行一根，`t` 是开盘时间的 Unix 毫秒，
`o/h/l/c` 是按 2 位小数取整的价格，`v` 是合成成交量。`h` 与 `l` 一定包住 `o` 与 `c`（体检里 `ohlc violations: 0`）。

## 来源

- 生成方式：一次性脚本，固定种子（`20250101` / `20250202` / `20250303`）的几何随机游走 + 轻微均值回归，
  每根的高低价在开收盘之外再抖一次，成交量在 0.6–1.5 倍之间随机。
- 不含任何交易所数据、不含任何真实成交记录、不引用任何第三方数据集；因此没有第三方许可要遵守。

## 校验摘要

```bash
node tools/data/inspect.mjs manifest assets/samples/btcusdt-1h.csv
```

`manifest` 打印绝对路径、`sha256`、格式与类型；教程 01 的第 3 步就是这么用的。想自己核对文件有没有被改过，
拿上面的 `sha256` 比一下即可（`sha256sum` / `shasum -a 256`）。
