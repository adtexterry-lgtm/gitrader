## 全系列契约

六张各讲一个主要利益：美股、加密、贵金属三个场景；DIY、专业开放、新手模拟三个使用动机。每张独立带原Gitrader标志和“开源底座 · M1 开发中”，无需依靠前一张解释。下列上图文案含短标/页脚约100–150汉字；受众、JTBD、依据与隐喻为策划注释，不上图。

统一品牌只作下一阶段边界：小原标志、黑+渐变橙、微软雅黑、克制玻璃质感。不六张复用同一个K线窗口，不用GPU/硬件盒子、币堆、火箭或收益曲线。隐喻仅建议，不含尺寸或生成指令。

资产页靠“美股/加密/贵金属”明确识别；美股/贵金属挂短标“接入构想 · 标的依场所”，不等于股票现货或实物已支持。加密页为链上交易场景，仍不声称真实主网执行已验收。DEX/交易所API路线区别现有与扩展；不得写全程上链、完全去中心化。每张只有一个文字CTA，无虚构网址/下载按钮。

## 01 · 美股：把想法组织成自己的系统

- 受众/JTBD：有自有研究方法的美股关注者；把研究接入可配置流程。
- 主要卖点：你的美股想法，可以成为你自己定义的交易工作流。
- 标题两行：**把美股灵感 / 写成交易规则**
- 支持两行：围绕你关注的美股，组合自己的智能体、数据与引擎。 / 把研究与执行接成你的工作流，标的随连接场所扩展。
- 三点：自选数据 / 自有引擎 / 规则自定
- CTA：了解美股接入
- 短标：接入构想 · 标的依场所
- 依据：F1/F3/O1；资产类别与连接框架，不当全美股覆盖证明。
- 隐喻：美股自选清单与一张研究卡汇入自定义工作流；无公司Logo。

## 02 · 加密：执行边界由你决定

- 受众/JTBD：已理解加密交易的用户；保留自有策略与授权控制。
- 主要卖点：让AI参与交易，同时由你设定它能做什么。
- 标题两行：**让你的 AI / 接入链上市场**
- 支持两行：面向DEX链上交易，在你的环境运行自己的策略。 / 从只读到限额自动，权限边界由你设定，行动有据可查。
- 三点：私有运行 / 分级授权 / 资金不托管
- CTA：了解连接方式
- 短标：场景构想 · 接入以当前能力为准
- 依据：F1/F2/F4/O1；链上场所场景不等于本地账本上链。
- 隐喻：一张交易提案经过授权闸口抵达链上场所；无“全链”拓扑。

## 03 · 贵金属：不同资产，同样由你定义

- 受众/JTBD：关注黄金/白银的策略研究者；组织自有数据与交易方法。
- 主要卖点：把贵金属相关场景纳入自己的AI交易流程。
- 标题两行：**黄金与白银 / 也有你的交易方式**
- 支持两行：把黄金、白银相关场景纳入你自己的AI交易工作流。 / 自带数据与策略，按已接入场所选择标的，保留你的判断。
- 三点：自带策略 / 自选场所 / 操作可查
- CTA：探索贵金属接入
- 短标：接入构想 · 标的依场所
- 依据：F1/F3/O1；metals分类不等于全贵金属市场或实物交割。
- 隐喻：明确标“黄金/白银”的双行情刻度与策略对照，非金条堆砌。

## 04 · DIY：自己构建，才真正顺手

- 受众/JTBD：DIY构建者；把已有工具组合为专属系统。
- 主要卖点：真实配置选择形成自己的使用方式（IKEA效应）。
- 标题两行：**你的交易引擎 / 就该与众不同**
- 支持两行：选自己的智能体、引擎和场所，把想法组合成专属工作流。 / 从策略到授权按你的方法配置，让工具适应你自己的交易习惯。
- 三点：模块组合 / 私有运行 / 规则自定
- CTA：规划你的第一套组合
- 短标：配置概念示意
- 依据：F1/O1；“不同”指个性化配置，不指行业唯一或平台提供策略。
- 隐喻：软件配置画布上，用户选择的三块配置形成一个专属签名；无积木硬件。

## 05 · 专业开放：把熟悉的引擎接进来

- 受众/JTBD：开发者与专业构建者；保留引擎，自主优化执行。
- 主要卖点：开放接口承接你的实现，不以通用模板限制你的方法。
- 标题两行：**保留你的专业 / 定制引擎性能**
- 支持两行：用MCP接入智能体，用开放协议连接任意语言的自有引擎。 / 按你的策略优化执行；DEX与交易所API沿接入路线逐步扩展。
- 三点：核心开源 / 协议开放 / 自主优化
- CTA：查看开发接入说明
- 短标：交易所API为扩展方向
- 依据：F1/F2/O1；交易所API并非多家现成连接器，专业性能表达不用基准数字。
- 隐喻：自有引擎接入开放接口的精密软件剖面，DEX/API两路清楚区分。

## 06 · 新手模拟：先理解，再配置

- 受众/JTBD：AI交易学习者；低门槛理解行为与权限，不先冒实盘风险。
- 主要卖点：把第一步缩小为一次可观察的纸面运行（降低启动门槛）。
- 标题两行：**先在模拟盘 / 跑通第一笔交易**
- 支持两行：先让自己的策略跑纸面，看看智能体做了什么、为何执行。 / 在工作台检阅持仓、活动与风险，再按理解逐步配置权限。
- 三点：模拟起步 / 工作台检阅 / 分级授权
- CTA：了解纸面起步
- 短标：入门路径示意
- 依据：F1/F4/K1；纸面与检阅有文档依据，不许加内置赚钱策略包或免配置承诺。
- 隐喻：一次纸面行动展开成“动作/原因/风控”三条学习记录，非业绩榜。
