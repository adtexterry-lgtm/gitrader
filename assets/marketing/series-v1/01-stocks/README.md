# Gitrader 系列海报 01 · 美股

`poster.png`（2048×3072）是跨机器主稿，`poster-preview.png` 为 1024×1536 预览。原始背景为 `scene.png`；其真实来源尺寸和 SHA-256 见 `MANIFEST.json`，主视觉按内置 Imagegen 提示生成一次并原字节嵌入，没有重绘或重采样保存源图。

`poster.svg` 保留原生可编辑文字并嵌入品牌字标与场景图；打开/渲染需要 Microsoft YaHei（微软雅黑）。可用 `render-poster.mjs` 复跑。文案和生成提示见系列根目录 [版式数据](../layout.json) 与 [提示词](../PROMPTS.md#01-stocks)；统一规则见 [施工图](../BLUEPRINT.md)。
