# Gitrader 0.1.1 — release notes

0.1.1 is the first public release and supersedes the 0.1.0 preview build. It keeps the same scope (paper trading, research, MCP and CLI for agents) and adds a round of usability, safety and documentation fixes found in end-to-end review.

## English

### What is new since 0.1.0

- **Risk metrics in backtests.** Results now include Sortino, Calmar, drawdown recovery time, and VaR / CVaR.
- **Safer backtest data.** Candle history is checked for readiness before a run, and missing bars are recovered instead of silently skewing results. Spec errors name the offending field, and the default engine is picked for you.
- **Experiments are easier to follow.** The experiment detail page shows the data and provenance (hypothesis, strategy, parameters, hold-out window, model used), can attach a paper run, and can export an evidence pack from the UI. Hold-out windows fall back sensibly.
- **Workbench.** New "Available" tab on the strategies page and the ability to start a paper strategy from the catalog; the funds page has a portfolio card; Records can be opened per symbol (`#/records/<symbol>`) and has a "Blocked" tab; the plugin switch shows whether a plugin is actually running. A visual pass fixed spacing, chart axes, the 390 px and 1024 px layouts, and the session-expired card.
- **Agent keys.** `gitrader keys rotate agent` rotates a key and the old token stops working immediately. Revoked or expired keys report `KEY_REVOKED` / `KEY_EXPIRED`, and the MCP tool list is cleared with a list-changed notice.
- **Clearer rejections.** Rejected orders come with a plain explanation and a stop-loss hint; takeover status shows the scope of the mandate; market search uses the symbol-search skill.
- **Notifications.** Each notification carries an idempotency key (also sent as an `Idempotency-Key` header by the webhook plugin), and a rejected order produces one message, not several. The four chat-app notification plugins accept an `apiBase` parameter (https, any origin).
- **Plugins.** Installed plugins can be re-verified on demand and record when they were last verified.
- **Doctor and status.** `gitrader doctor` flags unset or placeholder credential handles. `gitrader status` (with or without `--json`) exits 0 whenever the state can be read — not initialised, service stopped, or running — and prints the state plus the next command (`gitrader init` / `gitrader serve --detach`); it exits non-zero only when the state cannot be read. Commands that need a local session now also point agents to `gitrader agent …` when no session exists.
- **English workbench.** The workbench can be switched between Chinese and English under Settings · Personalization · Language; the default follows the browser language, and the page reloads after switching. Some free-text messages from the kernel (for example engine flow nodes and reports) are still Chinese in the English UI.
- **Smoother first run.** Rejected orders carry a hint on what to change next; `serve --detach` now says that no restart is needed after setting a PIN and that `gitrader open` prints a fresh link; the agent guide asks for a single agent key per session (or `--token-file` on every command when several exist) and warns against restarting the service when a sign-in link expires.
- **Docs.** Plugin rejection codes in the protocol doc match the code; the English guide gained the testnet account preparation chapter; bot examples and the report README run as written; the self-check scripts cover more of the config and metrics.

### How to install

**npm (Node >= 22.13)**

```text
npm install -g gitrader
gitrader init
gitrader serve
gitrader doctor
```

**Portable bundle (Node included)**

Download `gitrader-0.1.1-win-x64.zip`, `gitrader-0.1.1-linux-x64.tar.gz` or `gitrader-0.1.1-darwin-arm64.tar.gz`, unpack it, and run `start.cmd` (Windows) or `./start.sh` (macOS / Linux). There is no global command; use the bundled launcher (`bin\gitrader.cmd` or `bin/gitrader`).

**Docker**

The container setup is in `docker/`. Build with `docker compose build` and start with `docker compose up -d --build`. The host port must equal `GITRADER_PORT` (set in `.env`); the service validates the `Host` header and rejects mismatches with `403 Host not allowed`.

### Known limitations

- **Mainnet live trading is not supported in 0.1.1.** Configured mainnet live orders are rejected, and `gitrader doctor` reports it. Mainnet watch accounts and paper trading on mainnet market data still work.
- **Testnet live ordering is experimental** and has not been fully validated on the real network.
- **No installer and no code signing.** Windows SmartScreen and macOS Gatekeeper may warn.
- **Parameter optimization is single-process.**
- **No mainland China market data sources.**
- **Some CLI help and messages are Chinese-only for now.**
- **No strategies, data or advice.** Gitrader ships no strategies, market datasets or factors, gives no trading advice and does not custody funds.

The full list is in [Known limitations](https://github.com/adtexterry-lgtm/gitrader/blob/main/docs/user/en/21-%E5%B7%B2%E7%9F%A5%E9%99%90%E5%88%B6.md). Release checksums are published next to the assets (`SHA256SUMS`).

## 中文

0.1.1 是第一个公开发布版本，取代 0.1.0 预览构建。范围不变（纸面交易、研究、给 Agent 用的 MCP 与 CLI），并补上端到端复核中发现的一批易用性、安全和文档问题。

### 比 0.1.0 多了什么

- **回测风险指标。** 结果新增 Sortino、Calmar、回撤恢复时长、VaR / CVaR。
- **回测数据更稳。** 运行前先检查 K 线是否就绪，缺的 bar 会补回来，不再悄悄让结果走样；配置出错时会指出是哪个字段，默认引擎自动选好。
- **实验更好读。** 实验详情页展示数据与来历（假设、策略、参数、留出窗口、用到的大模型），可以在界面里附加纸面运行、导出证据包；留出窗口有合理的回退。
- **工作台。** 策略页新增「可用」页签，可从目录直接启动纸面策略；资金页有组合卡；记录页可按标的打开（`#/records/<标的>`），并新增「被拦」页签；插件开关如实反映插件是否在运行。一轮视觉修整处理了间距、图表坐标轴、390 与 1024 宽度下的版面，以及会话过期卡片。
- **Agent 钥匙。** `gitrader keys rotate agent` 轮换钥匙，旧令牌立即失效；吊销或过期会给出 `KEY_REVOKED` / `KEY_EXPIRED`，MCP 工具表随之清空并通知客户端。
- **拒单说明更清楚。** 被拒订单附中文说明和止损提示；接管后的状态含授权书作用域；行情搜索走标的搜索技能。
- **通知。** 每条通知带幂等键（webhook 插件同时放进 `Idempotency-Key` 头），一次拒单只发一条；四个即时通讯通知插件支持 `apiBase` 参数（https，任意来源）。
- **插件。** 已装插件可随时重新校验，并记录上次校验时间。
- **doctor 与 status。** `gitrader doctor` 会提示未设置或仍是占位值的凭据句柄；`gitrader status`（带不带 `--json` 都一样）只要查得出状态——没初始化、服务没起、在运行——就退出 0，并写明状态与下一步命令（`gitrader init` / `gitrader serve --detach`）；只有查不出状态才非 0。需要本机会话的命令在没会话时，报错里也会告诉 Agent 改走 `gitrader agent …`。
- **工作台英文界面。** 设置 · 个性化里新增「语言」卡，可在中文与英文间切换，默认跟随浏览器语言；切换后页面重新加载。部分内核自由文本（如引擎流程节点、报表）在英文界面下仍是中文。
- **新手上手更顺。** 被拒订单的提示附带下一步该怎么改；`serve --detach` 的输出说明设好 PIN 后无需重启、要新链接用 `gitrader open`；Agent 指南强调全程只建一把 Agent 钥匙，已有多把时每条命令带 `--token-file`，并避免为“链接过期”重启服务。
- **文档。** 协议文档里的插件拒绝码与代码一致；英文指南补了测试网账户准备一篇；机器人示例和报告 README 里的命令能直接跑；自带检查脚本覆盖更多配置和指标。

### 已知限制

- **主网实盘交易在 0.1.1 不开放。** 配了主网实盘账户，下单会被拒绝，`gitrader doctor` 会提示。主网观察账户、用主网行情做纸面交易不受影响。
- **测试网实盘下单是实验性功能**，尚未在真实网络上完整验证。
- **不提供安装程序，也没有代码签名。** Windows SmartScreen、macOS Gatekeeper 可能会弹警告。
- **参数寻优是单进程。**
- **不含中国市场数据源。**
- **部分 CLI 帮助和提示目前只有中文。**
- **不提供策略、数据或建议。** Gitrader 不提供策略、行情数据集或因子，不给交易建议，不托管资金。

完整清单见 [已知限制](https://github.com/adtexterry-lgtm/gitrader/blob/main/docs/user/21-%E5%B7%B2%E7%9F%A5%E9%99%90%E5%88%B6.md)。校验和见发布资产旁的 `SHA256SUMS`。
