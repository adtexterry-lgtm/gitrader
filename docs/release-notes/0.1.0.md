# Gitrader 0.1.0 — release notes

0.1.0 is the first public developer preview. It is meant for people who want to try agent trading safely on paper, run research, and connect an agent over MCP or the CLI.

## English

### What is in it

- **Paper trading.** Strategies run against a paper account; no order reaches a venue.
- **Backtesting and research.** The MCP `research` tool and the `gitrader research` subcommands cover backtests, walk-forward validation, factor reports, portfolio analysis and symbol search.
- **Four bot templates.** Grid, DCA, martingale and trend as configurable paper templates: `bot-grid`, `bot-dca`, `bot-martingale`, `bot-trend`.
- **Read-only watch accounts.** Follow the public positions and balances of any address on mainnet or testnet, with no key and no trading ability.
- **MCP and CLI for agents.** Connect an agent over MCP or the CLI; `gitrader mcp snippet` produces paste-ready host configuration.
- **Ledger export and verification.** `gitrader ledger export` writes JSONL, a manifest and a Markdown trade record; `gitrader ledger verify` recomputes the hash chain.
- **Documentation in English and Chinese.**

### How to install

**npm (Node >= 22.13)**

```text
npm install -g gitrader
gitrader init
gitrader serve
gitrader doctor
```

**Portable zip (Node included)**

Download `gitrader-0.1.0-win-x64.zip`, `gitrader-0.1.0-linux-x64.zip` or `gitrader-0.1.0-darwin-arm64.zip`, unpack it, and run `start.cmd` (Windows) or `./start.sh` (macOS / Linux). There is no global command; use the bundled launcher (`bin\gitrader.cmd` or `bin/gitrader`).

**Docker**

The container setup is in `docker/`. It runs `gitrader serve` with the data in a named volume and publishes to `127.0.0.1` by default. Build with `docker compose build` and start with `docker compose up -d --build`. On the first run, if the data directory is not yet initialised, the container automatically runs `init --no-pin` before starting `serve`, then prints a one-time workbench link in the logs (valid for two minutes, single use). Open it in your browser to set the PIN. Alternatively, you can set the PIN interactively in the terminal before starting the service. `docker/README.md` covers both approaches, backup and upgrades.

**Port rule:** The host port must equal `GITRADER_PORT` (set in `.env`). The service validates the `Host` header to prevent DNS rebinding attacks and rejects mismatches with `403 Host not allowed`.

### Known limitations

- **Mainnet live trading is not supported in 0.1.0.** Configured mainnet live orders are rejected, and `gitrader doctor` reports it. Mainnet watch accounts and paper trading on mainnet market data still work.
- **Testnet live ordering is experimental** and has not yet been fully validated on the real network. Hyperliquid testnet requires that an address has previously deposited on mainnet before it can authorise an agent wallet and place orders; this release uses only testnet tokens and has not been tested with real funds, so the primary evidence for the trading path is paper accounts and offline fixture tests.
- **No installer and no code signing.** There is no EXE, MSI or pkg. Portable bundles and release assets are not code-signed, so Windows SmartScreen and macOS Gatekeeper may warn.
- **Parameter optimization is single-process** and does not use multiple cores.
- **No mainland China market data sources.**
- **Some CLI help and messages are Chinese-only for now.**
- **No strategies, data or advice.** Gitrader ships no strategies, market datasets or factors, gives no trading advice and does not custody funds.

The full list is in [Known limitations](https://github.com/adtexterry-lgtm/gitrader/blob/main/docs/user/en/21-%E5%B7%B2%E7%9F%A5%E9%99%90%E5%88%B6.md). Release checksums are published next to the assets.

## 中文

0.1.0 是第一个公开的开发者预览，适合先在纸面上安全试用 Agent 交易、跑研究，并用 MCP 或 CLI 接上 Agent。

### 有什么

- **纸面交易。** 策略在纸面账户上跑，任何订单都不会发到场所。
- **回测与研究。** MCP 的 `research` 工具和 `gitrader research` 子命令覆盖回测、滚动样本外验证、因子报告、组合分析与标的搜索。
- **四个机器人模板。** 网格、定投、马丁、趋势，参数可调，纸面使用：`bot-grid`、`bot-dca`、`bot-martingale`、`bot-trend`。
- **只读观察账户。** 看任意公开地址的持仓与余额，主网、测试网都可以；不要钥匙，也不能下单。
- **用 MCP + CLI 接 Agent。** `gitrader mcp snippet` 直接产出可粘贴的宿主配置。
- **账本导出与核验。** `gitrader ledger export` 导出 JSONL、清单和 Markdown 交易记录；`gitrader ledger verify` 重算哈希链。
- **中英文档。**

### 怎么装

**npm（Node >= 22.13）**

```text
npm install -g gitrader
gitrader init
gitrader serve
gitrader doctor
```

**便携 zip（自带 Node）**

下载 `gitrader-0.1.0-win-x64.zip`、`gitrader-0.1.0-linux-x64.zip` 或 `gitrader-0.1.0-darwin-arm64.zip`，解压后运行 `start.cmd`（Windows）或 `./start.sh`（macOS / Linux）。没有全局命令，用包里自带的启动器（`bin\gitrader.cmd` 或 `bin/gitrader`）。

**Docker**

容器交付在 `docker/`：一个容器跑 `gitrader serve`，数据放具名卷，默认只在 `127.0.0.1` 监听。用 `docker compose build` 构建，`docker compose up -d --build` 启动。首次运行时，如果数据目录未初始化，容器会在启动 `serve` 之前自动运行 `init --no-pin`，然后在日志里打印一条一次性工作台链接（两分钟有效、只能用一次）。在浏览器里打开它来设置 PIN。你也可以在启动服务前先在终端里交互设置 PIN。两种做法、备份与升级见 `docker/README.zh-CN.md`。

**端口规则：** 宿主端口必须等于 `GITRADER_PORT`（在 `.env` 里设）。服务会校验 `Host` 头以防 DNS 重绑定攻击，不匹配会返回 `403 Host not allowed`。

### 已知限制

- **主网实盘交易在 0.1.0 不开放。** 配了主网实盘账户，下单也会被拒绝，`gitrader doctor` 会提示。主网观察账户、用主网行情做纸面交易都不受影响。
- **测试网实盘下单是实验性功能**，尚未在真实网络上完整验证。Hyperliquid 测试网要求地址先在主网有过入金，才能授权代理钱包与下单；本版只用测试币、没有用真钱测试过，所以交易链路的主要证据是纸面账户与离线夹具测试。
- **不提供安装程序，也没有代码签名。** 没有 EXE / MSI / pkg；便携包和发布资产没有代码签名，Windows SmartScreen、macOS Gatekeeper 可能会弹警告。
- **参数寻优是单进程**，不做多核并行。
- **不含中国市场数据源。**
- **部分 CLI 帮助和提示目前只有中文。**
- **不提供策略、数据或建议。** Gitrader 不提供策略、行情数据集或因子，不给交易建议，不托管资金。

完整清单见 [已知限制](https://github.com/adtexterry-lgtm/gitrader/blob/main/docs/user/21-%E5%B7%B2%E7%9F%A5%E9%99%90%E5%88%B6.md)。发布资产旁会给出校验和。
