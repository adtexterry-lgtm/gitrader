# 性能基准（M1，2026-10-10，v3）

> 口径按产品定义 §六：除注明外报 p50 / p95；首次与热启分开；**全部离线**（Hyperliquid 用 `fixtures/hl/` 夹具与回放，不含网络与场所处理时间）。达不到目标的如实写。v1 / v2 / v3 = 三轮验收，同机同脚本（`node scripts/verify/perf.mjs`）。

## 说明

- 下单开销：v2 逐段计时发现每笔 7 次 SQLite 提交（`synchronous=FULL`，每次一次 fsync）占 21 ms 中的约 15 ms；v3 由内核把"发往场所前 / 后"的写入各并成一个事务（7 → 2 次提交），"先写意图再调连接器"不变。H 复测 p50 7.0 / p95 10.9 ms（B 自报 6.9 / 10.0）。
- 纸面长尾：v2 时模拟场所每笔走一次 REST `l2Book`，约 290 笔后打满权重、下一笔卡 48 s；v3 改读 WS l2Book 本地快照（陈旧才限频兜底），H 复测 420 笔连发无阻塞、权重 12%。
