# 四个要 key 的行情源

Gitrader 的行情连接器分两种：**免 key 的**（加密场所那一批，直接读公共行情，注册进 `gitrader serve` 的场所表）和**要 key 的**（下面这四个，美股 / 全球股票的第三方数据商）。这一页只讲后者：key 从哪个环境变量来、免费档给你什么、免费档拿不到什么、出错时映射成哪个错误码。

## 1. 四家一览

| 数据商 | 包 | 环境变量 | 免费档限流（`describe().rateLimits` 声明值） | 只读 |
|---|---|---|---|---|
| Alpha Vantage | `@gitrader/connector-alphavantage-data` | `ALPHAVANTAGE_API_KEY`（其次 `ALPHA_VANTAGE_API_KEY`） | 25 次 / 天（按 IP） | 是 |
| Finnhub | `@gitrader/connector-finnhub-data` | `FINNHUB_API_KEY` | 60 次 / 分钟（按 IP，按调用次数计，不按权重） | 是 |
| Polygon | `@gitrader/connector-polygon-data` | `POLYGON_API_KEY` | 5 次 / 分钟（按账户） | 是 |
| Twelve Data | `@gitrader/connector-twelvedata-data` | `TWELVEDATA_API_KEY` | 8 credits / 分钟 + 800 credits / 天 | 是 |

四个都声明 `x-data-only: true`：只做行情，不碰资金、不持有交易凭据。

**key 只从环境变量进。** 也可以构造时用参数 `apiKey` 显式传入（优先于环境变量），但**不要写进配置文件**：配置文件会进哈希、进签名、进账本。缺 key 时构造即抛错（Alpha Vantage / Polygon 抛 `VENUE_AUTH`，Finnhub / Twelve Data 抛 `INVALID_PARAMS`），错误消息里只出现变量名，不出现 key 内容；上游若在错误体里回显 key，出站前替换成 `<redacted>`。

## 2. 免费档能给什么、拿不到什么

| 数据商 | 免费档能用 | 免费档拿不到 |
|---|---|---|
| Alpha Vantage | 日线 `compact`（最近 100 根）、周线 / 月线（整段历史）、`GLOBAL_QUOTE`、`LISTING_STATUS` | 任何盘中周期（`1m` / `5m` / `15m` / `30m` / `1h`，`TIME_SERIES_INTRADAY` 整个端点是付费）、日线 `n > 100`、日线带 `from`（会走 `outputsize=full`）；没有买卖盘（`book` 直接抛 `CAPABILITY_UNSUPPORTED`，不造档位） |
| Finnhub | 标的清单、`quote`、`marketStatus`、`marketHolidays` | `candles`（`/stock/candle`）与 `book` / `bidAsk`（`/stock/bidask`）官方标为付费，免费 key 回 403 |
| Polygon | 近 2 年历史与分钟聚合（收盘后更新） | 快照类端点（`refreshQuote` / `quote` 的刷新、`book` 的一档 NBBO、`context`、`subscribe({channel:'quote'})`）在免费档回 403 |
| Twelve Data | 股票清单、`time_series`、`quote`、`market_state`（按你账户的计划） | 计划外的端点 / 标的（回 401 / 403）；没有买卖盘（`x-book: 'none'`） |

**「拿不到」不会静默变成空数据**：付费门槛一律映射成 `VENUE_AUTH`，不重试；参数或标的不对映射成 `INVALID_PARAMS`。

## 3. 出错时你看到什么

| 上游表现 | 映射 |
|---|---|
| Alpha Vantage 超限 / 无权限：HTTP 200，body 是 `Information` / `Note` | 文本含 `premium` → `VENUE_AUTH`（不重试、不罚预算）；其余 → `VENUE_UNAVAILABLE`（`retryable: true`，约 60 秒后重试）,并让预算退避 |
| Alpha Vantage `Error Message` | `INVALID_PARAMS`（不重试） |
| Finnhub 403（付费端点） | `VENUE_AUTH`（不重试） |
| Polygon 429 / 403 | 429 → `VENUE_UNAVAILABLE`（带 `Retry-After`）；403 → `VENUE_AUTH` |
| Twelve Data 429（或 HTTP 200 带 `{status:"error", code:429}`）、401 / 403、400 / 404 | 429 → `VENUE_UNAVAILABLE`（`retryable: true`）；401 / 403 → `VENUE_AUTH`；400 / 404 → `INVALID_PARAMS` |

## 4. 限流怎么处理

四个连接器都**不自己睡眠等待**：它们在每个请求前向注入的 `budget` 要额度（优先 `acquire(weight)`，其次 `take(weight)`），成功后 `reportOk()`；预算缺省不限。要真正守住免费档，把预算建到 `describe().rateLimits` 声明的数字上：

```ts
import { AlphaVantageDataConnector } from '@gitrader/connector-alphavantage-data'

const conn = new AlphaVantageDataConnector({ budget })   // key 从 ALPHAVANTAGE_API_KEY 读
conn.describe().rateLimits   // [{ scope: 'ip', model: 'count', limit: 25, windowMs: 86_400_000, note: … }]
```

一次拉不完就分页：`describe().history` 声明了单次根数上限与页数上限；Polygon 首次启动会按 `instrumentPages`（缺省 100 页 × 1000 支）翻清单，免费档 5 次/分钟时这一步会慢，**标的很多时把 `instrumentPages` 调小，或直接用已知代码 `getInstrument()`**。

## 5. 现在能怎么用、还不能怎么用

- **能**：在代码里 `new` 一个连接器实例，`start()`、`listInstruments()`、`candles()`、`refreshQuote()`，喂给回测（`data.source: 'files'` 之外的数据来源）、喂给 `@gitrader/symbol-search` 建索引。
- **不能**：这四家**没有注册进 `gitrader serve` 的场所表**。想在界面里点着用，得先有注册，那是主会话排期的事。
- 四个包都**不联网跑测试**：测试用各自包里的假服务器，回官方形状的响应与错误码。

## 6. 三条硬话

1. **免费档没有的东西，不要靠重试去等**：付费墙不是限流，重试只会把配额耗光并拿到同样的 403。
2. **限流数字来自官方**（各包 README 里写了出处页面）：数字会变，以你账户控制台为准；`describe().rateLimits` 是软件声明，不是你合同的上限。
3. **数据商的口径与交易所不同**：复权、时区、交易日历、延迟都不一样。回测报告里要写清用的是谁的数据、什么时候拉的。
