# 已知限制（0.1.1）

Gitrader 0.1.1 是**开发者预览**。这一篇列出还没做的、还没验证的、以及你不该假设的东西。每一条都适用于这个版本本身；能用的部分在其他用户文档里讲。

## 1. 主网实盘交易在 0.1.1 不开放

这个版本没有**主网实盘交易**。配置了主网实盘账户，下单会被内核拒绝，`gitrader doctor` 会报出这个问题并告诉你该改什么。这是有意为之的限制，不是配置写错了。

两条相关路径不受影响：

- **主网只读观察账户照常可用。** 观察账户只要一个公开地址，不拿钥匙，永远不能下单。
- **用主网行情做纸面交易照常可用。** 纸面账户可以吃主网的报价与 K 线，成交全部留在本机。

## 2. 测试网实盘下单是实验性功能

0.1.1 里，**在测试网下真实订单**是实验性功能，尚未在真实网络上完整验证。请把它当测试路径：小仓位、盯住账本与对账输出，不要拿它承担任何重要的东西。

Hyperliquid 测试网要求地址先在主网有过入金，才能授权代理钱包与下单。本版只用测试币、没有用真钱测试过，所以交易链路的主要证据是纸面账户与离线夹具测试。

## 3. 不提供安装程序，也没有代码签名

Gitrader 不提供 EXE、MSI 或 pkg 安装程序。正式支持的包是 npm 包和便携 zip 包。

便携包和发布资产**没有代码签名**，Windows SmartScreen、macOS Gatekeeper 可能会弹警告。启动便携包之前，先核对随发布一起给出的校验和。

**Docker 镜像不发布到镜像仓库。** 0.1.1 只提供 `docker/` 下的构建文件，用户本地 `docker compose build`。

## 4. 参数寻优是单进程

参数寻优只跑一个进程，不做多核并行。大网格或进化搜索要花的时间就是单核需要的时间，排期时按这个算。

## 5. 不含中国市场数据源

Gitrader 不带中国市场的行情数据源。随包的场所连接器与连接路径，只覆盖用户文档里写到的那些场所。

## 6. 部分 CLI 帮助和提示只有中文

目前部分 CLI 帮助文本和运行时提示只有中文。英文用户文档描述的是同一批命令与字段；两边不一致时，以命令输出和源码为准。

## 7. 不提供策略、数据、因子或建议

Gitrader **不提供策略、不提供行情数据集、不提供因子**，不给交易建议，也不托管资金。机器人模板是参数可调的骨架，不是推荐；引擎本身不带任何历史数据——用你自己的文件，或在本地录制行情。

引擎、协议包和接口才是产品。交易什么、用什么数据、按什么规则，都是你自己的事。
