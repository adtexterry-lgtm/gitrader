# 教程 02 · 写一个策略，回测它，出报告

这条教程写**同一个策略的两版**（TypeScript 与 Python，钩子与参数语义一致），各自回测一遍，
把结果装进 `@gitrader/report` 的报告里。跑完你会得到两份 JSON、两份 Markdown、两份 HTML。

前置同 [教程 01](01-数据到因子报告.md)：命令在仓库根目录执行，产物写到 `./tutorial-lab/`（没有就先建，见第 0 步）。
Python 版需要 `python` ≥ 3.11 在 PATH 上（零第三方依赖；不在 PATH 就先看 `packages/engine-python/README.md`）。

## 0. 练习目录

```bash
mkdir -p ./tutorial-lab
```

## 1. 策略在 Gitrader 里是什么

一个策略就是**一个纯函数**：给它 K 线和参数，它给每一根 K 线一个**目标仓位**（-1 到 +1），
外加一句人话理由。它不下单、不算手数、不碰场所——引擎把目标仓位的变化翻成订单意图。

| 输出 | 类型 | 要求 |
|---|---|---|
| `target` | number[n] | 每根都在 [-1, 1]，预热期填 0 |
| `reasons` | string[n] | 只在目标变化的那根写理由，其余空串 |
| `overlays` | {名称: (number\|null)[n]} | 画在价格图上的线，可空 |
| `warmup` | integer | 第一根有效信号的序号 |

两条硬规矩：**不能前视**（第 i 根只能看 `candles[0..i]`），**必须确定**（同输入同输出，不读时钟、不用随机数）。

## 2. TypeScript 版

策略是"文件夹里的一个文件"：`~/.gitrader/engines/gitrader-core/strategies/`（内核自己的内置引擎）。
本教程为了不碰你的真实主目录，直接把文件放在仓库里已经准备好的位置
`docs/user/tutorials/strategies/tutorial-sma-band.ts`，下面的代码就是那个文件的内容，可以照抄到你自己的目录：

```ts
// SPDX-License-Identifier: CPAL-1.0
// 教程 02 的 TS 策略：均线偏离回归（教学用）。
//
// 规则：收盘价高出 N 根简单均线 band% 以上 → 目标 -1（满仓空）；低于 band% 以下 → 目标 +1（满仓多）；
// 回到带内 → 目标 0（空仓）。每根只用当前及更早的 K 线（无前视），无状态、无随机。
// 这类规则在震荡行情里经常吃到回归，在单边趋势里会持续逆势——没有任何业绩含义，只用来演示范式。
type Candle = { t: number; o: number; h: number; l: number; c: number; v: number }

type ParamDef = {
  key: string
  label: string
  type: 'number' | 'integer' | 'boolean'
  default: number | boolean | string
  min?: number
  max?: number
  step?: number
  help?: string
}

type SignalSeries = { target: number[]; reasons: string[]; overlays: Record<string, Array<number | null>>; warmup: number }

type StrategyDef = {
  id: string
  name: string
  nameZh?: string
  version: string
  desc: string
  tags: string[]
  params: ParamDef[]
  evaluate(candles: Candle[], params: Record<string, number | boolean | string>): SignalSeries
}

/** 尾部窗口的简单均值（只看 candles[i-period+1 .. i]）。 */
function smaAt(closes: number[], i: number, period: number): number | null {
  if (i + 1 < period) return null
  let sum = 0
  for (let j = i + 1 - period; j <= i; j++) sum += closes[j]!
  return sum / period
}

const strategy: StrategyDef = {
  id: 'tutorial-sma-band',
  name: 'SMA band reversion (tutorial)',
  nameZh: '均线偏离回归（教程）',
  version: '0.1.0',
  desc: '收盘高出 N 根均线 band% 做空、低出 band% 做多，回到带内空仓。震荡行情里吃回归，单边趋势里会反复逆势。',
  tags: ['教程', '均值回归'],
  params: [
    { key: 'period', label: '均线周期（根）', type: 'integer', default: 24, min: 5, max: 200, step: 1 },
    { key: 'band', label: '偏离带（%）', type: 'number', default: 1, min: 0.1, max: 10, step: 0.1 },
    { key: 'allowShort', label: '允许做空', type: 'boolean', default: true },
  ],

  evaluate(candles, params) {
    const n = candles.length
    const period = Math.max(2, Math.floor(Number(params.period)))
    const band = Number(params.band)
    const allowShort = Boolean(params.allowShort)
    const closes = candles.map((c) => c.c)
    const target: number[] = new Array(n).fill(0)
    const reasons: string[] = new Array(n).fill('')
    const line: Array<number | null> = new Array(n).fill(null)
    let prev = 0
    for (let i = 0; i < n; i++) {
      const ma = smaAt(closes, i, period)
      line[i] = ma
      if (ma === null) continue
      const upper = ma * (1 + band / 100)
      const lower = ma * (1 - band / 100)
      const px = closes[i]!
      let next = 0
      if (px > upper) next = allowShort ? -1 : 0
      else if (px < lower) next = 1
      target[i] = next
      if (next !== prev) {
        const side = next === 1 ? '做多' : next === -1 ? '做空' : '空仓'
        const where = px > upper ? `收盘 ${px} 高于上带 ${upper.toFixed(2)}` : px < lower ? `收盘 ${px} 低于下带 ${lower.toFixed(2)}` : `收盘 ${px} 回到带内`
        reasons[i] = `${where}（均线 ${ma.toFixed(2)}，±${band}%）→ ${side}`
        prev = next
      }
    }
    return { target, reasons, overlays: { SMA: line }, warmup: period - 1 }
  },
}

export default strategy
```

规则的读法：收盘价高出 N 根均线 `band%` 以上 → 目标 -1（满仓空）；低于 `band%` 以下 → 目标 +1（满仓多）；
回到带内 → 目标 0（空仓）。这是**均值回归**的骨架：震荡行情里顺势吃到回归，单边趋势里会一直逆势，
所以它的回测大概率不好看——这不是 bug，是这类规则的已知形态。

## 3. Python 版

同一个策略的 Python 版：文件级变量叫 `STRATEGY`（相当于 TS 的 `export default`），`params` 与 `evaluate` 一一对应。
策略文件**不能 import 任何模块**（沙箱策略档），需要什么就写在文件里：

```python
# SPDX-License-Identifier: CPAL-1.0
"""教程 02 的 Python 策略：均线偏离回归（与 strategies/tutorial-sma-band.ts 同名、同参数、同语义）。

规则：收盘价高出 N 根简单均线 band% 以上 → 目标 -1（满仓空）；低于 band% 以下 → 目标 +1（满仓多）；
回到带内 → 目标 0（空仓）。每根只用当前及更早的 K 线（无前视），无状态、无随机。
策略文件自包含：不 import 任何模块（沙箱策略档禁止 import），需要什么就写在文件里。
"""


def sma_at(closes, i, period):
    """只看 closes[i-period+1 .. i] 的简单均值；数据不够返回 None。"""
    if i + 1 < period:
        return None
    total = 0.0
    for j in range(i + 1 - period, i + 1):
        total += closes[j]
    return total / period


def evaluate(candles, p):
    n = len(candles)
    period = max(2, int(p["period"]))
    band = float(p["band"])
    allow_short = bool(p["allowShort"])
    closes = [c["c"] for c in candles]
    target = [0.0] * n
    reasons = [""] * n
    line = [None] * n
    prev = 0
    for i in range(n):
        ma = sma_at(closes, i, period)
        line[i] = ma
        if ma is None:
            continue
        upper = ma * (1 + band / 100)
        lower = ma * (1 - band / 100)
        px = closes[i]
        if px > upper:
            nxt = -1 if allow_short else 0
        elif px < lower:
            nxt = 1
        else:
            nxt = 0
        target[i] = float(nxt)
        if nxt != prev:
            if px > upper:
                where = "收盘 %.2f 高于上带 %.2f" % (px, upper)
            elif px < lower:
                where = "收盘 %.2f 低于下带 %.2f" % (px, lower)
            else:
                where = "收盘 %.2f 回到带内" % px
            side = "做多" if nxt == 1 else ("做空" if nxt == -1 else "空仓")
            reasons[i] = "%s（均线 %.2f，±%s%%）→ %s" % (where, ma, band, side)
            prev = nxt
    return {"target": target, "reasons": reasons, "overlays": {"SMA": line}, "warmup": period - 1}


STRATEGY = {
    "id": "tutorial-sma-band",
    "name": "SMA band reversion (tutorial)",
    "nameZh": "均线偏离回归（教程）",
    "version": "0.1.0",
    "desc": "收盘高出 N 根均线 band% 做空、低出 band% 做多，回到带内空仓。震荡行情里吃回归，单边趋势里会反复逆势。",
    "tags": ["教程", "均值回归"],
    "params": [
        {"key": "period", "label": "均线周期（根）", "type": "integer", "default": 24, "min": 5, "max": 200, "step": 1},
        {"key": "band", "label": "偏离带（%）", "type": "number", "default": 1, "min": 0.1, "max": 10, "step": 0.1},
        {"key": "allowShort", "label": "允许做空", "type": "boolean", "default": True},
    ],
    "evaluate": evaluate,
}
```

两版同名（`tutorial-sma-band`）、同参数（`period` / `band` / `allowShort`）、同语义——
所以两份回测结果应当逐笔对齐。

## 4. 回测 TypeScript 版

命令行没有回测子命令（回测在引擎侧，见 `docs/user/04-回测与研究.md`「回测入口」）。教程用一个薄脚本直接调
引擎库里的同一份回测代码：`loadStrategyFile`（校验 + 加载）→ `runBacktest`（信号 → 撮合 → 统计）：

```bash
node docs/user/tutorials/backtest.mjs --engine ts \
  --strategy docs/user/tutorials/strategies/tutorial-sma-band.ts \
  --data assets/samples/btcusdt-1h.csv \
  --out ./tutorial-lab/result-ts.json \
  --params '{"period":24,"band":1,"allowShort":true}' \
  --balance 10000 --leverage 1 --fee-rate 0.0005 --slippage-bps 3
```

输出大概是：

```text
回测完成（gitrader-core · 策略 tutorial-sma-band）
  K 线 1500 根 · 成交 96 笔 · 期末权益 9367.86
  总收益 -6.32% · 最大回撤 10.25% · 夏普 -1.706
```

`--params` 只给声明的键：没声明的键会被丢掉，超出 `min`/`max` 的值会被夹到边界（例如 `band: 20` 按 10 跑），引擎都不报错——改完参数先看一眼成交笔数是否合理。

## 5. 回测 Python 版

```bash
node docs/user/tutorials/backtest.mjs --engine py \
  --strategy docs/user/tutorials/strategies/tutorial-sma-band.py \
  --data assets/samples/btcusdt-1h.csv \
  --out ./tutorial-lab/result-py.json \
  --params '{"period":24,"band":1,"allowShort":true}' \
  --balance 10000 --leverage 1 --fee-rate 0.0005 --slippage-bps 3
```

两边的模拟器是按同一份口径对齐的（next-bar-open 成交、吃单费率、不利滑点、手数归一），
所以上面两条命令的统计量应当**逐项相同**：成交 96 笔、期末权益 9367.86、夏普 -1.706。

## 6. 出报告

`@gitrader/report` 把一份结果 JSON 渲染成 Markdown 和单文件 HTML（内联 CSS 与 SVG，没有 `<script>`、没有外链）：

```bash
node docs/user/tutorials/report.mjs ./tutorial-lab/result-ts.json \
  --md ./tutorial-lab/report-ts.md --html ./tutorial-lab/report-ts.html \
  --title "教程 · 均线偏离回归（TS）"
```

```bash
node docs/user/tutorials/report.mjs ./tutorial-lab/result-py.json \
  --md ./tutorial-lab/report-py.md --html ./tutorial-lab/report-py.html \
  --title "教程 · 均线偏离回归（Python）"
```

报告章节是：摘要 → 数据质量与假设 → 指标 → 曲线与月度收益 → 风险 → 参数 → 交易明细 → 方法 → 免责声明。
HTML 里三张图（权益曲线、回撤曲线、月度收益热力表）都是内联 SVG，可以直接发给别人看。

## 7. 报告读什么

| 看什么 | 在哪里 | 为什么 |
|---|---|---|
| `assumptions` | 报告的「数据质量与假设」 | 费、滑点、成交模型、资金费、强平五项；`funding` / `liquidation` 是 `false` 就是**没建模**，不是"没有成本" |
| `trades` / `fills` | 指标区 | 成交笔数决定手续费量级；本策略 96 笔、手续费 919.72，收益里很大一块被它吃掉 |
| 最大回撤与夏普 | 指标区 | 和总收益一起看；单看收益会把波动藏起来 |
| `biasChecks` | 结果 JSON | 前视检查结果与 `trialCount`（这条策略被试了多少组参数）；试得多、只有一组好看，基本等于运气 |
| 交易明细的 `reason` | 报告最后一节 | 策略自己写的那句人话，复盘时先看它再看价格 |

`trialCount` 在本教程里是 1（只跑了一组参数）。真做研究时它是你的诚实项：`sweep-report.mjs`
扫过的每一组参数都要算进去，见 `tools/research/README.md`。
