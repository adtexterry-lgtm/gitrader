# Gitrader 用户文档

写给**用**Gitrader 的人：装好、跑通第一条策略、看懂配置、接上通知与插件、出事时知道按哪里。

语言 / Language：中文 · [English](en/README.md)

- 协议字段级规范、施工口径在仓库的 `docs/` 下（如 `docs/config.md`、`docs/plugins.md`、`docs/risk-gate-protocol.md`、`docs/security.md`），那些是给实现者看的；这里只讲你怎么用。
- 事实来源：命令行分支在 `packages/cli/src/index.ts`，配置字段与默认值在 `packages/kernel/src/config.ts`。**文档与代码不一致时以代码为准**；本目录自带离线校验脚本，见文末。

## 三条按人群的读法

- **第一次用**：01 全篇 → 02 只看「顶层字段」和 `server` → 03 前半段。
- **要写策略、跑回测**：03 → 04。04 里关于假设（费用、滑点、资金费、强平）的一节不要跳。
- **准备接真钱**：05 全篇 → 09 的「保证与不保证」→ 02 的 `risk` 与 `accounts`。

## 约定

- 命令行统一写成 `gitrader <子命令>`。没有全局安装时，它等于 `npx gitrader <子命令>`。完整清单随时可看：`gitrader help`（不带参数运行也给同样的帮助）。
- 主目录默认 `~/.gitrader`，用环境变量 `GITRADER_HOME` 或参数 `--home DIR` 改。本文档里出现的路径都在这个主目录下。
- 所有示例账户都是**纸面账户**；示例里出现的数字是参数，不是收益预期。
- 每条命令都在本仓库的 CLI 分支里存在；本文档不描述还没实现的命令。

## 文档自检

```text

```

脚本离线跑，做四件事：把文档里出现的 `gitrader <子命令>` 与 CLI 的 `case` 集合比对；把反引号里的配置键与 `packages/kernel/src/config.ts` 的字段比对；扫产品文案禁词；扫本机绝对路径。不一致会逐条列出并以退出码 1 结束。
