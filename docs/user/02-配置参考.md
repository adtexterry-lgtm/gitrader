# 配置参考

一份文件管全部：`~/.gitrader/gitrader.json`。`gitrader init` 生成默认内容，之后随你改。字段、默认值、校验规则都来自 `packages/kernel/src/config.ts`；校验不过的文件会让内核**拒绝启动并列出所有问题**，不做静默修正。

## 通用规则

- **内核启动时读一次**，M1 没有热重载：改完要重启 `gitrader serve`。
- 文件里**不放任何密钥**：只放钥匙库里的名字（`signerRef`）与公开地址；令牌一律写句柄（`env:变量名`）。
- 十进制数值（名义额、比例）写成**字符串**，如 `"2000"`、`"0.03"`；计数、秒数、倍数是数字。
- 有一处例外：`risk` 段**只能收紧**。写得比已签名的风控策略更宽的部分会被忽略并在启动告警里说明；放宽要在工作台里输 PIN（或 `gitrader risk relax`）。
- 工作台里切网络（主网 / 测试网）会改写 `venues[].environment` 与 `accounts[].environment`，并提示需要重启。

## 顶层字段

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `schema` | 字符串 | `"gitrader-config/1"` | 必须原样是这个值，改了就启动不了 |
| `supportDeveloper` | 布尔 | `false` | 「支持开发者」开关：打开后 Hyperliquid 订单带 1 bp 的 Builder 费（还需你在主钱包另外授权）；关着照常交易。`init` 不会问你 |
| `venues` | 数组 | 见下 | 场所 |
| `accounts` | 数组 | 见下 | 账户 |
| `engines` | 数组 | 见下 | 引擎 |
| `risk` | 对象 | 见下 | 风控种子 |
| `keys` | 对象 | 见下 | 钥匙默认值 |
| `layout` | 对象 | `{"workspace":"ws_default"}` | 默认工作区名；M1 只校验、不读取 |
| `server` | 对象 | `{"port":null}` | 本地服务端口 |
| `plugins` | 对象 | `{"developerMode":false,"trustRoots":[]}` | 插件 |
| `embed` | 对象 | `{"allowedOrigins":[]}` | 允许把工作台嵌进 iframe 的上层页面源 |

## `venues`：场所

默认：`[{"id":"hyperliquid","environment":"testnet","enabled":true}]`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | 字符串 | 小写字母、数字、短横线。可用的场所见下面的能力表 |
| `environment` | `"mainnet"` \| `"testnet"` | 网络 |
| `enabled` | 布尔 | 是否启用 |

主网默认关着：在工作台里切到主网之前，必须先导入或生成一只**主网** API 钱包（见 05）。

**哪些场所能用、能做到哪一步**（`id` 填第一列；「只读」= 行情，「测试网 / 主网」= 能不能下单）：

| 场所 `id` | 只读 | 测试网下单 | 主网下单 | 说明 |
|---|---|---|---|---|
| `hyperliquid` | 是 | 是 | 是 | 随包、默认启用；主网要先导入主网 API 钱包 |
| `ibkr` | 是 | 是 | 否 | 要本机 IB 网关；`symbols` 里列出要用的代码；主网实盘未开放 |
| `binance` | 是 | 是 | 否 | 测试网下单要在实盘账户里写凭据句柄；主网只给行情 |
| `okx` | 是 | 是 | 否 | 同上，另需 passphrase |
| `bybit` | 是 | 是 | 否 | 同 binance |
| `bitget` | 是 | 是 | 否 | 同 okx |
| `gateio` | 是 | 是 | 否 | 同 binance |
| `alpaca` | 是 | 是 | 否 | 股票；纸面环境可下单，主网实盘账户只给行情 |
| `kraken` | 是 | 否 | 否 | 只有行情 |
| `coinbase` | 是 | 否 | 否 | 只有行情 |
| `kucoin` | 是 | 否 | 否 | 只有行情 |
| `deribit` | 是 | 否 | 否 | 只有行情 |
| `dydx` | 是 | 否 | 否 | 只有行情（下单连接器还没接线） |

启用另一个场所，在 `venues` 里加一项（缺省的 `hyperliquid` 保留），重启服务：

```json
{
  "venues": [
    { "id": "hyperliquid", "environment": "testnet", "enabled": true },
    { "id": "okx", "environment": "mainnet", "enabled": true }
  ]
}
```

没有配置的场所，`market` 工具会直接回 `INSTRUMENT_UNKNOWN` 并点名场所，不会假装有行情。

## `accounts`：账户

默认一个纸面账户，别名不许重复。`accountId` 由 `init` 自动补，不要手改。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `alias` | 字符串 | 是 | 命令行与 Agent 都用它指代账户 |
| `venue` | 字符串 | 是 | 对应 `venues[].id` |
| `environment` | `"mainnet"` \| `"testnet"` | 是 | 网络 |
| `mode` | `"paper"` \| `"live"` \| `"shadow"` \| `"watch"` | 是 | 纸面（吃真实行情的模拟撮合）/ 实盘 / 影子（当前与纸面走同一模拟撮合路径）/ 观察（只读，按公开地址看持仓和余额，不要钥匙、不能下单） |
| `paper` | `{initialBalance, ccy}` | `mode=paper` 时必填 | `initialBalance` 是十进制字符串 |
| `watch` | `{address}` | `mode=watch` 时必填 | 要观察的公开地址（`0x` 加 40 位十六进制）。观察账户不许再写 `signerRef`、`credentials`、`paper`；场所只支持 `hyperliquid`，`environment` 按它自己的网络读公开数据、不必和场所连的网络一致。用 `gitrader accounts watch <地址>` 加，不用手写 |
| `signerRef` | 字符串 | `mode=live` 时必填 | 钥匙库里 API 钱包的名字（`gitrader keys list` 能看到），**不是私钥** |
| `accounts[].owner.address` | 字符串 | 实盘建议填 | 你的主账户公开地址。Hyperliquid 里 API 钱包替主账户下单，余额 / 持仓 / 成交按主账户地址查；不填，启动时会告警，且这些数据跟踪不到 |

```json
{
  "accounts": [
    { "alias": "paper", "venue": "hyperliquid", "environment": "testnet", "mode": "paper",
      "paper": { "initialBalance": "10000", "ccy": "USDC" } },
    { "alias": "main-live", "venue": "hyperliquid", "environment": "mainnet", "mode": "live",
      "signerRef": "my-api-wallet",
      "owner": { "address": "0x0000000000000000000000000000000000000000" } }
  ]
}
```

## `engines`：引擎

默认：`[{"id":"gitrader-core","enabled":true,"builtin":true}]`

每项要有 `id`（小写字母、数字、`.`、`_`、`-`，不许重复）、`enabled`，再加三种形态之一：

| 形态 | 写法 | 行为 |
|---|---|---|
| 随包参考引擎 | `{"builtin": true}` | 内核把打包好的 `engine-core` 当 stdio 子进程拉起；找不到打包产物就只登记不启动（可用环境变量 `GITRADER_ENGINE_CORE_BUNDLE` 指定位置） |
| 本地任意语言子进程 | `{"launch": {"command": "...", "args": [...], "env": {...}, "cwd": "..."}}` | 内核拉起、健康检查，崩了退避重启（1 秒到 60 秒；10 分钟内崩 5 次判 failed）。子进程**不继承**你的环境变量，只拿到 `env` 里显式写的、`GITRADER_GEP_TOKEN` 和最小系统变量 |
| 已在跑的 ws / 远程 wss | `{"launch": {"url": "wss://...", "auth": {"method": "token", "tokenRef": "env:变量名"}}}` | `url` 必须是 `ws://` 或 `wss://`，非本机必须 `wss://`；**令牌不许写进 URL**；`auth` 里是句柄，不是令牌或证书本身 |

```json
{
  "engines": [
    { "id": "gitrader-core", "enabled": true, "builtin": true },
    { "id": "my-rust-engine", "enabled": true,
      "launch": { "command": "C:/engines/my-engine.exe", "args": ["--gep", "stdio"],
                  "env": { "MY_MODE": "paper" }, "cwd": "C:/engines" } },
    { "id": "partner-engine", "enabled": false,
      "launch": { "url": "wss://engine.example.com/gep",
                  "auth": { "method": "token", "tokenRef": "env:PARTNER_ENGINE_TOKEN" } } }
  ]
}
```

- 策略文件夹固定是 `~/.gitrader/engines/<id>/strategies/`（内置引擎的 `<id>` 是 `gitrader-core`）。
- 远程引擎的 `env:` 句柄从**启动 `gitrader serve` 的那个环境**里取，配置文件里只有变量名。其他形式的句柄（钥匙库条目）M1 未实现，会显示 failed；mTLS 未验。
- 引擎协议见 `docs/engine-protocol.md`；把引擎绑到账户要你本人输 PIN：`gitrader engines bind <id>`。

## `risk`：风控种子

默认：

```json
{
  "risk": {
    "preset": "p-lev3-o2000-d3",
    "limits": { "maxSlippageBps": 50, "maxOrdersPerMinute": 30, "maxCancelsPerMinute": 60, "duplicateIntentWindowSec": 10 },
    "protectors": [],
    "failClosed": { "stalePriceMs": 5000, "onMissingPrice": "deny" },
    "dailyResetAt": "00:00Z",
    "valuationCcy": "USDC"
  }
}
```

**这一段只是种子**：第一次启动时内核据此生成一份**签名的风控策略**存进数据库，之后以签名策略为准；文件里的 `risk` 只有比当前策略更严才会并入。

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `preset` | 字符串 | `p-lev3-o2000-d3` | 数字预设，三选一，id 里就是数字 |
| `limits` | 对象 | 见上 | 覆盖预设的同名字段 |
| `protectors` | 数组 | `[]` | 保护器；留空则用预设自带的 |
| `failClosed` | `{stalePriceMs, onMissingPrice}` | `{5000,"deny"}` | 行情陈旧超过 `stalePriceMs` 毫秒、或拿不到价格，一律拒单 |
| `denyLlmLiveEntries` | 布尔 | `true` | 大模型来源的 Agent 不得发起实盘开仓，只能提案等你批。写 `false` 属放宽，**写在文件里会被忽略**，要在工作台输 PIN 关 |
| `dailyResetAt` | 字符串 | `"00:00Z"` | 当日盈亏的基线时点 |
| `valuationCcy` | 字符串 | `"USDC"` | 估值币种 |
| `maxDriftBps` | 整数 ≥0 | 30 | 本地批准的价格偏离界限（bp）。配置只能收紧，放宽用人面 PIN |

**预设**：

| id | 杠杆 | 单笔名义 | 单标的占权益 | 总敞口占权益 | 持仓个数 | 日亏 | 冷却 |
|---|---|---|---|---|---|---|---|
| `p-lev3-o2000-d3`（默认） | ≤3× | ≤2,000 | 0.3 | 0.6 | 3 | 3% | 5 秒 |
| `p-lev5-o5000-d5` | ≤5× | ≤5,000 | 0.5 | 1 | 5 | 5% | 2 秒 |
| `p-lev10-o20000-d10` | ≤10× | ≤20,000 | 1 | 2 | 10 | 10% | 0 |

**`limits` 可用字段**（都可选；`maxSlippageBps` 缺省补 50）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `maxLeverage` | 数字 ≥0 | 杠杆上限 |
| `maxOrderNotional` | 十进制字符串 | 单笔名义额上限 |
| `maxPositionNotionalRatio` | 十进制字符串 | 单标的持仓名义 / 权益 |
| `maxTotalNotionalRatio` | 十进制字符串 | 全部持仓名义 / 权益 |
| `maxOpenPositions` | 数字 ≥0 | 持仓个数 |
| `maxDailyLossRatio` | 十进制字符串 | 当日权益回撤比例 |
| `maxDailyNotional` | 十进制字符串 | 单日名义额合计 |
| `maxSlippageBps` | 数字 ≥0 | 市价类滑点上限（bp） |
| `maxOrdersPerMinute` | 数字 ≥0 | 每分钟下单笔数（防刷单与场所限流） |
| `maxDailyOrders` | 数字 ≥0 | 每日下单笔数 |
| `maxCancelsPerMinute` | 数字 ≥0 | 每分钟撤单次数（降风险动作不受限） |
| `duplicateIntentWindowSec` | 数字 ≥0 | 窗口内同账户同标的同方向同价同量的重复意图直接拒；`0` 关闭（属放宽） |

**保护器种类**（可叠加，只会拒绝或收紧）：`cooldown`、`stoploss_guard`、`drawdown_pause`、`low_profit_lock`、`max_consecutive_failures`、`plugin`。字段与语义见 `docs/risk-gate-protocol.md` 与 `packages/kernel/src/protectors.ts`。

## `keys`：钥匙默认值

默认：`{"agentKeyExpiryDays":90,"defaultTier":"paper","walletExpiryWarnDays":14}`

| 字段 | 类型 | 说明 |
|---|---|---|
| `agentKeyExpiryDays` | 数字 >0 | 新建 Agent 钥匙的有效天数 |
| `defaultTier` | `"read_only"` \| `"paper"` \| `"confirm"` | 新钥匙默认档位。**不许写 `auto_limited`**：限额自动不能当默认 |
| `walletExpiryWarnDays` | 数字 | API 钱包到期前多少天开始提醒轮换 |

## `layout` / `server` / `plugins` / `embed`

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `layout.workspace` | 字符串 | `"ws_default"` | 默认工作区名 |
| `server.port` | 整数（1–65535）或 `null` | `null` | `null` = 从 47900 起自动找空闲端口，并避开一批常见端口；命令行 `--port` 优先。服务永远只绑 `127.0.0.1` |
| `plugins.developerMode` | 布尔 | `false` | 打开才加载**未签名**的插件（本地开发用）。未签名插件不能申请 `trade.live` / `venue.credentials` |
| `plugins.trustRoots` | `[{keyId, publicKey}]` | `[]` | 你手动信任的插件签名公钥；内置信任根 M1 为空 |
| `embed.allowedOrigins` | 字符串数组 | `[]` | 允许嵌工作台的页面源，形如 `https://host[:port]`，不许通配符 / 路径。空 = 禁止被嵌（`frame-ancestors 'none'`）。改完要重启 |

`embed.allowedOrigins` 可以用命令行改，不必手编文件：

```text
gitrader config get embed.allowedOrigins
gitrader config set embed.allowedOrigins https://app.example
gitrader config set embed.allowedOrigins none
```

## 主目录布局（环境变量 `GITRADER_HOME` 可改）

```text
~/.gitrader/
  gitrader.json    全部 DIY 面（本文档讲的就是它）
  plugins/         <目录名>/gitrader-plugin.json 丢进去就是安装
  engines/         <engine-id>/strategies/  策略文件
  workspaces/      工作台布局
  lab/             本机实验产物
  data/            gitrader.sqlite（账本 + 状态）
  keys/            pin.json / keystore.json / install-key.json / device.key.json
  service.json     运行中实例的端口与令牌（权限已收紧）
```

`keys/` 不要放进同步盘；它里面有 PIN 校验值、加密后的私钥、设备密钥。原因见 [09-安全](09-安全.md)。
