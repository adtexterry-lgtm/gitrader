# Gitrader × Claude Code

1. 装技能：运行 `gitrader skill install claude-code`；或者把本仓库的 `integrations/claude-code/SKILL.md` 放进项目里的 `.claude/skills/gitrader-onboarding/`。
2. 对 Claude Code 说一句话：「我想用 Gitrader 做纸面交易，帮我装好，并让你自己提一单买一点比特币，我来批准。」
3. 你只需要做两件事：在浏览器里输 PIN、在待批里点批准。

技能会按七步带你走：看现状、安装、起服务设 PIN、问清批准方式和限额、创建钥匙、接入宿主、提第一单带止损的纸面单。

---

## English

1. Install the skill: run `gitrader skill install claude-code`, or put `integrations/claude-code/SKILL.md` from this repository into `.claude/skills/gitrader-onboarding/` in your project.
2. Tell Claude Code: "I want to paper trade with Gitrader. Install it, then place a small BTC buy yourself and I will approve it."
3. You do two things: type your PIN in the browser, and click approve in the pending list.

The skill walks seven steps: check the current state, install, start the service and set the PIN, agree on approval mode and limits, create a key, connect the host, place a first paper order with a stop loss.
